# RAG-Based Hallucination Detection System

A production-grade, full-stack web application designed to automatically detect, classify, and explain factual hallucinations in answers generated by Retrieval-Augmented Generation (RAG) pipelines.

---

## Architecture & System Overview

```
User
 │
 ├──► Upload Document (PDF, DOCX, TXT, MD)
 │     │
 │     ▼
 │    Text Extraction ──► Chunking (Size & Overlap) ──► Embeddings ──► Vector Database
 │
 └──► Ask Question
       │
       ▼
      Context Retrieval (Top-K Chunks)
       │
       ▼
      Grounded LLM Answer Generation
       │
       ▼
      Claim Decomposition (Atomic Fact Extraction)
       │
       ▼
      Claim vs Context Verification (Entailment / Polarity / Similarity)
       │
       ├── SUPPORTED (Score: 1.0) ──► Exact Evidence Highlight
       ├── PARTIALLY_SUPPORTED (Score: 0.5) ──► Partial Context Match
       ├── UNSUPPORTED (Score: 0.0) ──► Hallucination Flagged
       └── CONTRADICTED (Score: 0.0) ──► Opposing Context Flagged
       │
       ▼
      Score Calculation (Support Score & Hallucination Score)
       │
       ▼
      Interactive UI Dashboard & Sentence Grounding Map
```

---

## Features

- **End-to-End RAG Pipeline**: Ingest PDF, DOCX, TXT, and Markdown files. Chunks preserve page numbers, chunk indices, and metadata.
- **Factual Claim-Level Verification**: Answers are decomposed into atomic claims and verified strictly against retrieved chunks without external bias.
- **Interactive Sentence Highlighting**: Color-coded sentence map (Green = Supported, Amber = Partially Supported, Red = Unsupported, Purple = Contradicted). Clicking any sentence reveals its supporting or conflicting context.
- **Real-Time Dynamic Dashboard**: All KPIs (Total Documents, Queries, Grounded Answers, Hallucination Rate, Score Distributions) are computed dynamically from backend databases.
- **Machine Learning Hallucination Classifier**: Scikit-learn + NLP feature union pipeline with training and evaluation tools.
- **Modern React + TypeScript + Tailwind UI**: Glassmorphic dark theme, responsive sidebar, Recharts graphs, and toast feedback.
- **JWT Authentication & Security**: Secure bcrypt hashing, OAuth2 Bearer tokens, and input validation.

## Technology Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, React Router v7, Axios, Recharts, Lucide React.
- **Backend**: Python 3.11+, FastAPI, Pydantic v2, SQLAlchemy 2.0, Uvicorn, Bcrypt, PyPDF, Python-docx.
- **Vector Search & ML**: Scikit-learn, TF-IDF + Cosine Similarity, Sentence Transformers fallback, Joblib.
- **Database**: SQLite for local development (configured cleanly for PostgreSQL migration).
- **Deployment**: Docker, Docker Compose, Nginx.

## Installation & Setup

### 1. Backend Setup

```bash
# Navigate to project root
cd NLPp

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Install dependencies
pip install -r backend/requirements.txt
```

### 2. Configure Environment Variables

```bash
cp backend/.env.example backend/.env
```

Default settings in `.env`:
```ini
APP_NAME="RAG-Based Hallucination Detection System"
APP_ENV=development
API_V1_PREFIX=/api
PORT=8000
HOST=0.0.0.0
SECRET_KEY=rag-hallucination-secret-key-change-in-production-2026-secure-random-seed
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440
DATABASE_URL=sqlite:///./rag_hallucination.db
UPLOAD_DIR=../data/documents
VECTOR_DB_DIR=../data/vectors
MAX_UPLOAD_SIZE_MB=25
DEFAULT_TOP_K=4
DEFAULT_CHUNK_SIZE=500
DEFAULT_CHUNK_OVERLAP=50
DEFAULT_TEMPERATURE=0.2
LLM_PROVIDER=extractive-grounded
```

### 3. Train ML Classifier

```bash
python training/train.py
python training/evaluate.py
```

### 4. Frontend Setup

```bash
cd frontend
npm install
npm run build
```

## How Hallucination Detection Works

1. **Answer Decomposition**:
   - The generated response is split into atomic, single-fact claims using linguistic heuristics.
2. **Context Verification**:
   - Each claim is independently checked against retrieved context chunks using lexical containment, cosine similarity, and negation/contradiction filters.
   - External knowledge is strictly ignored.
3. **Scoring Formula**:
   $$\text{Support Score} = \frac{\sum \text{Claim Scores}}{\text{Total Claims}}$$
   $$\text{Hallucination Score} = 1.0 - \text{Support Score}$$
4. **Classification Tiers**:
   - **0.90 – 1.00**: `NOT_HALLUCINATED` (Grounded)
   - **0.70 – 0.89**: `LOW_HALLUCINATION`
   - **0.40 – 0.69**: `MEDIUM_HALLUCINATION`
   - **0.00 – 0.39**: `HIGH_HALLUCINATION`

## API Endpoints Reference

### Authentication
- `POST /api/auth/register`: Register new account and receive JWT access token.
- `POST /api/auth/login`: Authenticate with email/password and obtain JWT.
- `GET /api/auth/me`: Retrieve current user profile.

### Document Management
- `POST /api/documents/upload`: Ingest PDF/DOCX/TXT/MD, extract text, chunk and index in vector store.
- `GET /api/documents`: List uploaded documents.
- `GET /api/documents/{id}`: View document chunk details and text segments.
- `DELETE /api/documents/{id}`: Delete document and remove vector representations.
- `POST /api/documents/{id}/reprocess`: Re-chunk and re-index document.

### RAG & Query
- `POST /api/query`: Full RAG pipeline (Retrieval -> Generation -> Claim Decomposition -> Verification -> Scoring -> Persistence).
- `GET /api/query/{id}`: Fetch previous query result with context and claims.

### Hallucination Evaluation
- `POST /api/evaluate`: Direct evaluation on custom question, answer, and context.
- `GET /api/evaluations`: List evaluation audit log with search, status filters, and pagination.
- `GET /api/evaluations/{id}`: Detailed evaluation drill-down.

### Dashboard & Analytics
- `GET /api/dashboard/stats`: Real-time KPI statistics.
- `GET /api/dashboard/charts`: Real-time chart telemetry.

### Settings
- `GET /api/settings`: Retrieve pipeline configuration.
- `PUT /api/settings`: Update LLM provider, temperature, Top-K, chunk parameters.
